# x86-64 与 AArch64 对照

本站实验主线在 x86-64 / SysV 上。AArch64 用作对照轴：同一高级语言构造落到不同 ISA 与 ABI 时，名字会变，几何关系往往还在。

## 寄存器与返回地址

x86-64 提供十六个通用整数寄存器，返回地址由 `call` 压栈，`ret` 弹出。AArch64 通用整数寄存器为 `x0`–`x30`（加 `sp`）；`x30` 作链路寄存器（LR）保存返回地址，叶函数常不把 LR 入栈。帧指针在 AArch64 约定里常用 `x29`。

条件码方面，x86 用 `RFLAGS` 与一长串 `jcc`；AArch64 多数整数比较写 `nzcv` 标志再分支，也有条件选择指令减少短分支。读反汇编时先找「比较/测试 → 分支」还是「比较 → 条件传送/选择」。

## 调用约定对照

SysV AMD64：整型参数 `rdi, rsi, rdx, rcx, r8, r9`，浮点 `xmm0`–`xmm7`。AAPCS64：整型 `x0`–`x7`，浮点 `v0`–`v7`。两边都对栈有 16 字节对齐要求。把「第 n 个整型参数在哪个寄存器」画成表，比背两套助记符更不易混。

## 寻址与编码风格

x86-64 指令长度可变，ModR/M 与可选 SIB/REX 前缀表达丰富的存储器操作数；RIP-relative 是 PIC 的核心手段之一。AArch64 指令字长固定 32 位，装载/存储与算术分离更整齐，立即数范围与寻址模式受固定宽度约束。同一种 C 表达式在两种 ISA 上的指令条数可以差很多，并不自动等于「哪边更快」。
