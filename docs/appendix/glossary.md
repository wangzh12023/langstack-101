# 术语表

首现章节以正文链接为准；本表作检索入口。中英并存时，对话里用英文缩写通常更稳。

| 术语 | 英文 | 简述 |
| --- | --- | --- |
| 指令集架构 | ISA | 软硬件契约：可见寄存器、指令、寻址与特权边界 |
| 应用二进制接口 | ABI | 函数如何传参/返回、栈对齐、符号与类型布局约定 |
| 系统 V AMD64 | SysV AMD64 ABI | Linux x86-64 用户态主流调用约定 |
| 红区 | red zone | SysV 下叶函数可在 `rsp` 下方 128 字节暂用的区域 |
| 可重定位目标文件 | relocatable object | `.o`；含重定位记录，待链接修补 |
| 全局偏移表 | GOT | 动态符号地址槽 |
| 过程链接表 | PLT | 外部调用跳板，常配合懒绑定 |
| 位置无关代码 | PIC/PIE | 不依赖装载绝对地址的代码形态 |
| 静态单赋值 | SSA | 每个变量名在静态上只赋值一次；合流处用 φ |
| 未定义行为 | UB | 抽象机未赋予语义的操作；编译器可假设其不发生 |
| 先发生 | happens-before | 内存模型里约束可见性的偏序关系 |
| 数据竞争 | data race | 冲突的并发访问且至少一方为非原子写（定义随语言而变） |
| 写屏障 | write barrier | GC 在指针写入时插入的记账/同步逻辑 |
| 胖指针 | fat pointer | 地址 + 额外元数据（长度、vtable 等） |
| 类型擦除 | type erasure | 编译期类型不进入或很少进入运行时表示 |
| 单态化 | monomorphization | 按具体类型生成特化代码 |
| 即时编译 | JIT | 运行期把字节码/IR 编成机器码 |
| 提前编译 | AOT | 运行前生成机器码 |
| DWARF | DWARF | 常见调试信息格式 |
| LLVM IR | LLVM IR | LLVM 的中间表示 |

随正文推进会继续增补。
