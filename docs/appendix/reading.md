# 推荐读物

按本站章节对应，不按「经典必读」口号排列。

## 机器与系统

- Bryant & O'Hallaron,《Computer Systems: A Programmer's Perspective》（CSAPP）：虚存、链接、异常控制流与程序机器级表示
- Intel / AMD 架构手册中与用户态相关的卷：指令编码、内存序与系统编程导读章节按需查

## 汇编与 ABI

- System V Application Binary Interface, AMD64 Architecture Processor Supplement（现行草案/发行版）：传参、红区、TLS
- `man 7 signal`、`man 2 syscall`：信号与系统调用的操作系统面

## 编译器与 LLVM

- Aho 等,《Compilers: Principles, Techniques, and Tools》选读：词法语法、中间表示与优化动机
- LLVM 官方文档：LangRef、Pass 导览；以能读 IR 与对照 asm 为界

## 语言与运行时

- ISO C / C++ 标准中「抽象机 / UB / 生命周期」相关条款（不必通读全书）
- 各语言规范或权威手册中关于内存模型、对象表示与 FFI 的章节：Go memory model、JLS、ECMAScript、Python data model 等
