# 口试量规

下列十题必须能在正文中指到具体段落（或图、反汇编片段）作答。任一题答不出，视为尚未达到「与导师对话不被拆穿」的标准。

1. **SysV 调用路径**  
   从 `call f` 到 `f` 首指令：返回地址、栈对齐、红区、调用者/被调用者保存寄存器；两个 `double` 参数走哪些寄存器。

2. **抽象机与 UB**  
   有符号溢出为何能让编译器删掉看似有用的检查；「我机器上这样跑」为何不是反例。

3. **PLT / GOT**  
   一次外部调用的路径；懒绑定前后 GOT 槽内容；`-fPIC` 对寻址形态的改变。

4. **进程入口**  
   为何入口不是 `main`；`ld.so`、辅助向量、到 `main` 之前发生了什么。

5. **SSA**  
   画菱形 CFG 并标 φ；说明 mem2reg 前后；`-O2` 后断点对不上局部变量的原因。

6. **LLVM 边界**  
   举一例语言语义在 IR 中消失或只剩 metadata（别名、生命周期、provenance 任选）。

7. **内存序**  
   数据竞争与竞态条件的区别；乱序执行与 store buffer 为何需要语言/硬件层的序。

8. **派发**  
   并排说明 C++ 虚调用、Go interface、Rust `dyn Trait` 的间接层与胖指针/对象头形态。

9. **GC 与所有权**  
   写屏障解决什么问题；与 RC/ARC 循环引用如何对照。

10. **基准**  
    为何朴素递归 fibonacci 的跨语言排名几乎不可直接解释；应追问整数宽度、溢出、尾调用、JIT warmup、是否测到启动或 GC。

## 通过线

十题均可回链到具体页；第 1、2、3、6、10 题为硬门槛，缺一即未通过。
