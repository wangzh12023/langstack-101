# 课程结构（现行）

## 主问题

程序文本如何变成可讨论的机器行为；语言差异是这条路径上的不同装置，不是互不相关的特性清单。

## 各章在路径上的角色

| 章 | 读者此时缺什么 | 读完应能做什么 |
| --- | --- | --- |
| 一 | 对「机器上的数与执行」只有口语印象 | 谈整数/浮点、缓存、虚存、内存序、ISA 时有共同词汇 |
| 二 | 无法指着一次 `call` 或一次启动说出字节级事实 | 沿调用、链接、装载把进程说圆；口试 Q1/Q3/Q4 |
| 三 | 不知道编译器凭什么改写第二章的对应 | 指着 IR/asm 说优化与语义边界；口试 Q5/Q6 |
| 四 | 比较语言时只会堆特性名 | 用轴描述差异，再进入分论 |
| 五 | 轴不会落地 | 对给定语言能讲到 ABI/运行时/执行模型 |
| 六 | 细节攒不回一张图 | 读基准、对话时能指回正文 |

## 目录收束

旧导航按细目平铺（寄存器、TLS、重定位各一页），读者会当成词表扫描，看不出下一步依赖上一步。现行导航只保留路径上的站；细目并进站内正文。旧单页仍留在仓库 `docs/ch0x/*.md` 供检索，但不进主导航；见 [旧版细目存档说明](legacy-pages.md)。
