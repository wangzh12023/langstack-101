# 课程大纲与验收

## 目标

读完本站后，能够在课题讨论中把「源码 → IR → 目标码 → ELF → 装载 → 执行 → 微架构」这条链讲清楚，并按同一组语义轴比较主流语言的实现取舍。口语标准：与导师对话时不被基础追问拆穿。

## 分层

| 部分 | 分类轴 | 作用 |
| --- | --- | --- |
| 一、机器与表示 | 硬件抽象层 | 程序最终落在比特、缓存、内存序与 ISA 上 |
| 二、汇编与二进制 | 从指令到进程映像 | 端到端读写 x86-64 机器行为 |
| 三、编译器与 LLVM | 编译流水线阶段 | 解释优化与 lowering，不要求贡献 LLVM |
| 四、语言共性 | 跨语言语义维度 | 类型、内存、执行、并发、UB、FFI |
| 五、语言分论 | 语言 | 只写落点与差异，共性回链第四章 |
| 六、心智图与对话清单 | 整合用途 | 读基准、自测口试 |

## 写作阶段

| 阶段 | 内容 | 完成标准 |
| --- | --- | --- |
| P0 | 站点骨架、规范、大纲、口试量规 | `mkdocs serve` 可浏览完整导航 |
| P1 | 第一章全部 | 能口述补码、缓存行、页表、内存序、ISA 契约 |
| P2 | 第二章至系统调用 + fib 初版 | 手写 asm 产出可运行 ELF，能自述 `objdump` |
| P3 | ELF、链接、重定位、PIC、装载；完善 fib | 能解释一条重定位如何改字节 |
| P4 | LLVM 主干与 C→IR→asm 实验 | 能指着 `-O2` 的 IR/asm 说出主要变化 |
| P5 | 第四章全部 | 语言页只填差异 |
| P6 | C、C++、Rust、Go | 四页都能讲到 ABI / 运行时落点 |
| P7 | Java/Kotlin、C#、Swift | 能对比 JVM / CLR / ARC |
| P8 | Python、JS/TS、动态运行时样本 | 能解释同算法数量级差异的机制 |
| P9 | 对照表、源码到硅片、读基准、对话清单 | 口试量规十题可指页作答 |
| P10 | 术语表、工具链、读物；交叉链接 | 术语无悬空，实验命令可复现 |
